# Pabrik Konten Otomatis — Public Website

This repository contains the public informational website for **Love a Little, Feel a Little More**, an independent creative-media project operated through Pabrik Konten Otomatis.

## Pages

- `index.html` — project homepage and contact information.
- `privacy.html` — privacy policy covering the website and the project's optional production integrations.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. GitHub will display the published Pages URL after deployment.

The expected URL for this repository is:

https://gadingsmart515-star.github.io/pabrik-konten-website/

Allow a few minutes for the first deployment. Confirm the homepage and privacy policy load before using their URLs in any third-party app configuration.

## Security

This is a public repository. Do not add OAuth client secrets, refresh tokens, credential JSON files, private production assets, or other confidential information here. Keep production automation and credentials in the separate private repository and protected GitHub Actions secrets.

GitHub Pages hosting and third-party service availability, policies, and requirements are controlled by their respective providers. A GitHub Pages URL is not a custom domain and may not satisfy every third-party domain-verification requirement.
